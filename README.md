# The Trial of LLM-01

Interactive microsite for the six-part mini series.

## Run locally

From this folder, start any static web server, for example:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Controls

- Click any of the six poster exhibits to open its chapter.
- Use the chapter rail to jump between exhibits.
- Press `1`–`6` to select a chapter.
- Press `Space` to play or pause.
- Press the left or right arrow to change chapters.
- Enable **Play all** for continuous playback.
